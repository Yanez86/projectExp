# projectExp

Browser game fantasy di economia ed esplorazione: guidi una gilda di mercanti su una mappa a
esagoni generata a ogni round. Gioca su PC e mobile, in italiano e inglese.

- Design del gioco: [docs/GDD.md](docs/GDD.md)
- Piano tecnico: [docs/TECH.md](docs/TECH.md)

## Avvio in locale

Serve Node.js 22.

```sh
npm install
npm run dev      # apre il gioco su http://localhost:5173
npm run check    # tipi, lint e test
npm run build    # build di produzione in apps/client/dist
```
